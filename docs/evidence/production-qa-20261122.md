## What needs live proof

1. **Background jobs and uploads.** Provide a host for the continuous worker and private scanner. The current Vercel plan offers 1 or 2 GiB instances and a monthly memory quota. The repository's combined production configuration requests 8 GiB. A read-only review of all eight waiting notification jobs found four staff grants, three queue assignments and one guardian invitation. The current routing function returned zero eligible accounts for these events. Recheck the queue immediately before activation because assignments and recipients can change. Then verify a clean upload, quarantine, a retry after interruption, and notification processing on that host. [Vercel daemon limits](https://vercel.com/docs/daemons/limits) · [Deployment instructions](../DEPLOYMENT.md)
2. **Sender and inbox.** The Mailjet sender is active and TLS SMTP authentication worked. The last actual invitation and recovery reached Spam. Sending through Mailjet with a Gmail From address limits domain authentication. For Mailjet, use an address on a domain Git Tutor controls, add the provider's SPF and DKIM records and verify DMARC alignment. For a free Gmail-address route, use Gmail itself if the owner selects it. Retire or rotate credentials previously shared in chat through private settings. A controlled recipient must report folder placement after the change. [Google sender guidelines](https://support.google.com/mail/answer/81126) · [Mailjet sender guidance](https://documentation.mailjet.com/hc/en-us/articles/360042759253-How-to-add-a-sender-address)
3. **Meet.** The owner must consent from the intended organizer account at production Admin → Integrations. Verify a private guest-free event, change, cancellation and reauthorization. Rehearse overlapping classes with two eligible organizers and a 90–105 minute group session with the approved test accounts. [Organizer setup](../GOOGLE-CALENDAR-SETUP.md)
4. **Finance and operations.** An owner must approve booking, cancellation, deposit and refund terms and the real collection accounts, assign settlement reviewers, approve tutor agreements and reconcile opening balances. Historical spreadsheet labels cannot authorize new financial postings. Configure these through the administration workflows.
5. **Recovery and opening the site.** Name a backup destination, recovery contact, tolerated data loss and downtime. Rehearse restoration on a separate host with private files and ledger checks before opening the production domain to customers. Confirm invitation and recovery through the ordinary customer path after changing the Vercel access setting. [Production inputs](../PRODUCTION-INPUTS.md)
