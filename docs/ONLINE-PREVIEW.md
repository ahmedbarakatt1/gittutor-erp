# Shared testing preview

Open [Git Tutor](https://gittutor-erp-rho.vercel.app) or [sign in](https://gittutor-erp-rho.vercel.app/login) on any device. The web app and background worker run on the hosted pilot. The selected deployment runs independently of the operator's laptop.

## Signing in and testing

Ask the owner for access to the appropriate test role through a private channel. The preview contains authorized workbook history and labelled practice activity. Use the prepared practice record when testing changes. Local development accounts belong to a different database. A new colleague can run the [synthetic rehearsal](DEMO-WALKTHROUGH.md) on their own checkout.

The ordinary pilot uses simulated provider operations and manual reconciliation. One designated one-to-one booking was authorized for real Google Meet and both participants joined. Customer and staff pages enforce role and record scope. The current launch decision, exact checks and limitations are in [implementation status](IMPLEMENTATION-STATUS.md).
